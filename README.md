# 미니게임

여러 미니게임을 방을 만들어 친구와 함께 즐기는 실시간 온라인 멀티플레이어 서비스입니다. 초대 코드로 방을 만들고(원하는 코드를 직접 지어도 됨) 친구를 초대해서 최대 8명까지 함께 플레이할 수 있습니다.

## 제공되는 미니게임

방에 들어가면 방장이 아래 미니게임 중 하나를 선택할 수 있고, 게임마다 다른 설정 항목이 나타납니다.

- **🎯 탱크 게임** — Tank Trouble 스타일 탱크 대전. 탱크 속도·연사 속도·총알 속도·목숨을 조절 가능. 총알이 벽에 맞으면 반사되어 튕기고, 정면은 장갑이라 막히지만 후면(약점)에 맞으면 목숨이 깎임. 홈 화면의 "🎯 탱크 혼자 연습하기" 버튼으로 대기방 없이 바로 혼자 연습 가능.
- **⚔️ 칼싸움** — 근접 전투 대전. 이동 속도·목숨 조절 가능. Space로 검을 휘둘러 사거리/각도 안의 상대에게 적중.
- **⚡ 반응속도 테스트** — 화면이 초록색으로 바뀌는 순간 가장 빨리 클릭(또는 Space)한 사람이 승리. 너무 빨리 누르면 부정 출발로 실격.
- **🔢 업다운 맞추기** — 서버가 정한 범위(방장이 설정 가능) 안의 비밀 숫자를 맞추는 게임. 추측할 때마다 업/다운 힌트를 받고, 가장 먼저 정답을 맞춘 사람이 승리.

## 공통 기능

- 닉네임 입력 후 "방 만들기"(원하는 초대 코드 직접 입력 가능, 비워두면 랜덤 생성) 또는 "초대 코드"로 참가
- 방에 모인 인원(2~8명)이 모두 "준비완료"를 누르면 자동으로 게임 시작
- 각 플레이어는 개인 화면에서 시야 범위(FOV, 줌 인/아웃)를 취향대로 조절 가능 (탱크/칼싸움 게임)
- 모바일 화면 좌상단 ⛶ 버튼으로 전체화면 모드 전환 가능 (iOS Safari는 브라우저 자체 제약으로 지원되지 않을 수 있음), 화면 조이스틱 + 발사/공격 버튼 지원
- 승리한 플레이어에게 점수 누적, 라운드 종료 후 자동으로 로비로 복귀

## 로컬에서 실행하기

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 여러 탭/기기에서 접속해 같은 초대 코드로 함께 플레이할 수 있습니다.

## Render 무료 호스팅 배포

1. 이 저장소를 GitHub에 push 합니다.
2. [Render](https://render.com)에 로그인 후 **New + → Blueprint** 선택, 이 저장소를 연결하면 `render.yaml` 설정이 자동으로 인식됩니다.
   - 또는 **New + → Web Service**로 직접 만들 경우:
     - Build Command: `npm install`
     - Start Command: `npm start`
     - Instance Type: Free
3. 배포가 끝나면 제공되는 `https://xxxx.onrender.com` 주소로 접속해서 플레이하면 됩니다.

> 참고: Render 무료 플랜은 트래픽이 없으면 슬립 상태가 되어 첫 접속 시 몇십 초 정도 로딩이 걸릴 수 있습니다.

## 구조

```
server/
  index.js        - Express + Socket.IO 서버, 방 상태에 따라 각 게임 모듈로 디스패치하는 게임 루프
  rooms.js        - 방/플레이어 상태, 커스텀 초대 코드, 게임별 설정 관리
  physics.js       - 이동/충돌/총알 물리 등 여러 게임이 공유하는 저수준 로직
  maps.js         - 아레나 맵(벽 좌표), 스폰 위치 정의 (탱크 게임 / 칼싸움 공용)
  games/
    registry.js   - 사용 가능한 미니게임 목록
    tank.js       - 탱크 게임 로직
    sword.js      - 칼싸움 로직
    reaction.js   - 반응속도 테스트 로직
    updown.js     - 업다운 맞추기 로직
public/
  index.html / style.css / main.js - 클라이언트 UI, 게임별 화면 전환, 캔버스 렌더링
```

새 미니게임을 추가하려면 `server/games/` 아래에 `{id, name, usesMap, realtime, settingsSchema, defaultSettings, start, tick, onInput, onAction, serialize}` 형태의 모듈을 만들고 `registry.js`에 등록하면 됩니다.
